# 02 · 安装、使用与调参

## 前置检查

| 项 | 要求 | 怎么确认 |
|---|---|---|
| 系统 | Windows 10 / 11 | — |
| Myth.Cool | 已安装且能正常显示 | 打开软件看一眼副屏是否亮 |
| Python | **3.9 或更高，且在 PATH 里** | 命令行敲 `python --version`，有版本号就行 |

**没装 Python？** 去 <https://www.python.org/downloads/> 下最新版，
安装时**务必勾上 `Add python.exe to PATH`**。

> 安装脚本会自己在 `C:\ProgramData\MythCoolInject\venv\` 里建一个**私有**
> Python 环境并装 frida —— 不会污染你系统里的 Python。

2. 右键 `tools\Install.bat` → **以管理员身份运行**

## 日常使用

装完就不用管了：

- **开机 / 登录** → 自动打补丁
- **睡醒**（软件被自愈脚本重启）→ 下一轮自动补上
- **手动重启软件** → 同上
- 平时每分钟只做一次「查 PID 比对」，~120ms，几乎没有开销

## 调参：改 `tune.json`

安装目录下的 `tune.json`，**改完保存约 1 秒生效** —— 不用重启软件、不用重跑安装。

### ⚠️⚠️ 第一件事：皮肤名是「本机实测」的，换机器必须先探测

上面那张表（`AeeBiCui` / `DreamMonitoring` / `FallFlower2`，编号 31/29/30）是
**在一台 VK03 机箱 + 一个特定 Myth.Cool 版本上实测出来的**，不是官方通用标准。

- 官方皮肤会增删、第三方皮肤会被收录或下架、**不同设备出厂带的皮肤也不一样**；
- 所以**换一台机器照抄这套名字，大概率认不出来**；
- 认不出来的后果是 `unknown` → 不在 `skins` 白名单 → **注入器不动界面**。
  这是故意设计的安全行为（宁可不动，也不能拿着错误的排版乱改别人的皮肤）。

**换机器 / 升级 Myth.Cool 后，先跑探测**（只读，不改任何东西）：

```powershell
& 'C:\ProgramData\MythCoolInject\venv\Scripts\python.exe' 'C:\ProgramData\MythCoolInject\skill\tools\probe_skins.py'
```

它会告诉你：当前皮肤的根容器 class、官方编号、**本机装了哪几套**（dial 编号列表）、
以及可以直接粘进 `tune.json` 的 `_skinRules` 骨架。
**每套皮肤都要切过去再跑一次**才能拿到它自己的类名和编号。

拿到之后写进 `tune.json` **顶层**（不要改代码）：

```jsonc
"_skinRules": {
  "byClass": { "AeeCui": "我的皮肤1", "MySkinRoot": "我的皮肤2" },
  "byMode":  { "31": "我的皮肤1", "17": "我的皮肤2" }
}
```

### ★ v21 起：布局按皮肤生效（先读这一段）

`tune.json` 现在是**分皮肤**结构。注入器会先识别当前皮肤，只在 `skins` 里列出的皮肤上改界面：

```jsonc
{
  "_skin": "auto",                    // auto=自动识别；也可写死 "AeeBiCui" 强制（调试用）
  "skins": {
    "AeeBiCui":         { "ix":169, "iy":150, ..., "css":"..." },  // 只有这套会改界面
    "DreamMonitoring":  { "_skip": true },                          // 梦境：不动
    "FallFlower2":      { "_skip": true }                           // 洛音：不动
  },
  "default": { "_skip": true }        // 兜底：自定义皮肤 / 没认出来的皮肤 -> 一律不动
}
```

| 皮肤 id | 对应 | 官方编号 | 识别判据（根容器 class） |
|---|---|---|---|
| `AeeBiCui` | 博物馆1（第三方作者，官方收录） | 31 | `.AeeCui` |
| `DreamMonitoring` | 梦境 | 29 | `.DreamMonitoring` |
| `FallFlower2` | 洛音（商店显示名） | 30 | `.FallFlower2` |

- **换皮肤时会自动撤销**本工具在那套皮肤上做过的全部改动（删样式表、删浮层、停定时器、
  把被隐藏的原生按钮显示回来），不用手动清理。
- **自定义皮肤**：它是独立窗口 `diySkin.html`，副屏主页面根本不加载 ⇒ 注入器不会运行。
  万一将来搬进主页面，识别结果会是 `unknown` → 落到 `default` → 不动界面。
- **想给别的皮肤也做排版**：在 `skins` 里复制一份段，去掉 `_skip` 再填数值。
  ⚠️ 数值必须按那套皮肤重新量（见下）。
- **想回到「所有皮肤都改」的老行为**：把整个 `skins` 段删掉即可（兼容旧 `tune.json`）。

> ⚠️ 别拿这些类名当判据：`.Dream_box` 是**公共子组件**（梦境和 AeeBiCui 里都有）；
> `.dial29` 是 dial31 在非 960 高度下的外层包裹 `div`，**都不是皮肤根**。

字段含义（写在 `skins.<皮肤id>` 段里；删除 `skins` 段时写在顶层）：

| 字段 | 含义 |
|---|---|
| `ix` | 新增数据项的**横向**位置（局部坐标） |
| `iy` / `idy` | 新增项的起始纵向位置 / 行距 |
| `tops` | 逐项覆盖纵向位置，如 `{"mbt":150,"memt":188,"vrt":226}` |
| `ifs` | 新增项字号（px） |
| `lw` | 标签宽度（em），用来让数值左边缘对齐 |
| `hide` | 要隐藏的项 id 数组，如 `["mbv"]` |
| `minw` `vm` `vg` `vfs` | 主排（内存/显存行）的数值预留宽 / 间距 / 字号 |
| `css` | **追加的任意 CSS** —— 排版的主战场 |
| `refresh_ms` | 新增项的自带刷新节拍（毫秒）。**<3500 会被保险丝自动抬到 3500**（避免与原生 3s 节拍同频撞拍；真要 <3500 需显式 `_allow_fast_tick: true`）—— 所以写 3000 不生效，别被日志里的原值骗了 |
<!-- v20 起 tick 参数已删除：它从不在代码默认值表里，从未生效过（v19 及之前的文档说法有误） -->

可用的项 id：

| id | 内容 |
|---|---|
| `mbt` | 主板温度 |
| `mbv` | 主板电压 |
| `memt` | 内存温度 |
| `vrt` | 显存温度 |

> ⚠️ `tune.json` 里预置的数值是按 **VK03 机箱副屏 + AeeBiCui「博物馆1」皮肤** 调出来的
> 示例。**换皮肤/换设备必须自己重新量**，否则位置会不对。

## 怎么量位置（坐标系统）

Myth.Cool 的副屏内容是 `rotate(90deg)` 渲染的（屏幕物理上竖装），所以：

- **`.AeeCui` 是定位容器**，它的局部坐标 `(x, y)` ≈ 用户视角坐标 `(x+2, y+2)`
- **x 增大 = 往右；y 增大 = 往下**（用户视角）
- `style.left` 控制的是用户视角的**横向**，`style.top` 是**纵向**

**怎么知道自己皮肤的长什么样**：把 `tune.json` 的 `css` 先清空、`hide` 改成 `[]`，
重启 Myth.Cool 就回到原始皮肤，然后参考 `assets/coords.png` 的做法标注着量。

## 常见改造配方

### 加一个新数据项

1. 先看有哪些数据可用：在皮肤页面里
   `JSON.parse(localStorage.bg_sensor_data)` —— 里面所有字段都能取
2. 在 `inject_main.py` 的 `ITEMS` 数组里加一条：

```js
var ITEMS = [
  { id: 'mbt',  label: '主板温度', key: 'mb_t' },
  { id: 'cpu_f', label: 'CPU频率', key: 'cpu_f' },   // ← 新增
];
```

3. 在 `vals()` 里补上取值：

```js
function vals() {
  ...
  return {
    mb_t: f(mb.temp, 'C'),
    cpu_f: f(cpu.freq, 'MHz'),   // ← 新增
  };
}
```

4. 在 `tune.json` 的 `tops` 里给它一个位置

### 改字号 / 颜色

在 `tune.json` 的 `css` 里加：

```css
.mtc-it{font-size:24px !important;color:#ffd700 !important;}
```

### 挪动主排（内存/显存行）

```css
.ProgressBar.outside.AeeAndCui{transform:translateY(-6px) !important;}
```

## ⚠️ 改 CSS 之前必读

**改任何选择器之前，先确认这个选择器匹配几个元素。**

方法：在皮肤页面 console 里跑

```js
document.querySelectorAll('你的选择器').length
```

原因：Myth.Cool 的类名很多来自**配置数据**（`customClass`），不是写死的字面量 ——
同一个类会被**多个 Vue 组件实例复用**。本项目就因为这个踩过大坑（见 [04-踩坑合集](04-踩坑合集.md) 第 2 条）。

**优先用「运行时内容特征」定位**（比如"块里的 span 文本是 `MB/s`"），而不是类名。
