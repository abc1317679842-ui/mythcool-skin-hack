# 02 · 安装、使用与调参

## 前置检查

| 项 | 要求 | 怎么确认 |
|---|---|---|
| 系统 | Windows 10 / 11 | — |
| Myth.Cool | 已安装且能正常显示 | 打开软件看一眼副屏是否亮 |
| Python | **3.9 或更高，且在 PATH 里** | 命令行敲 `python --version`，有版本号就行 |

**没装 Python？** 去 <https://www.python.org/downloads/> 下最新版，
安装时**务必勾上 `Add python.exe to PATH`**。

> 安装脚本会自己在 `C:\ProgramData\MythCoolInject\venv\` 里建一个**私有**
> Python 环境并装 frida —— 不会污染你系统里的 Python。

2. 右键 `tools\Install.bat` → **以管理员身份运行**
3. 看着它跑完 5 步

## 日常使用

装完就不用管了：

- **开机 / 登录** → 自动打补丁
- **睡醒**（软件被自愈脚本重启）→ 下一轮自动补上
- **手动重启软件** → 同上
- 平时每分钟只做一次「查 PID 比对」，~120ms，几乎没有开销

## 调参：改 `tune.json`

安装目录下的 `tune.json`，**改完保存约 1 秒生效** —— 不用重启软件、不用重跑安装。

字段含义：

| 字段 | 含义 |
|---|---|
| `ix` | 新增数据项的**横向**位置（局部坐标） |
| `iy` / `idy` | 新增项的起始纵向位置 / 行距 |
| `tops` | 逐项覆盖纵向位置，如 `{"mbt":150,"memt":188,"vrt":226}` |
| `ifs` | 新增项字号（px） |
| `lw` | 标签宽度（em），用来让数值左边缘对齐 |
| `hide` | 要隐藏的项 id 数组，如 `["mbv"]` |
| `minw` `vm` `vg` `vfs` | 主排（内存/显存行）的数值预留宽 / 间距 / 字号 |
| `css` | **追加的任意 CSS** —— 排版的主战场 |
| `refresh_ms` | 新增项的自带刷新节拍（毫秒）。**<3500 会被保险丝自动抬到 3500**（避免与原生 3s 节拍同频撞拍；真要 <3500 需显式 `_allow_fast_tick: true`）—— 所以写 3000 不生效，别被日志里的原值骗了 |
<!-- v20 起 tick 参数已删除：它从不在代码默认值表里，从未生效过（v19 及之前的文档说法有误） -->

可用的项 id：

| id | 内容 |
|---|---|
| `mbt` | 主板温度 |
| `mbv` | 主板电压 |
| `memt` | 内存温度 |
| `vrt` | 显存温度 |

> ⚠️ `tune.json` 里预置的数值是按 **VK03 机箱副屏 + AeeBiCui「博物馆1」皮肤** 调出来的
> 示例。**换皮肤/换设备必须自己重新量**，否则位置会不对。

## 怎么量位置（坐标系统）

Myth.Cool 的副屏内容是 `rotate(90deg)` 渲染的（屏幕物理上竖装），所以：

- **`.AeeCui` 是定位容器**，它的局部坐标 `(x, y)` ≈ 用户视角坐标 `(x+2, y+2)`
- **x 增大 = 往右；y 增大 = 往下**（用户视角）
- `style.left` 控制的是用户视角的**横向**，`style.top` 是**纵向**

**怎么知道自己皮肤的长什么样**：把 `tune.json` 的 `css` 先清空、`hide` 改成 `[]`，
重启 Myth.Cool 就回到原始皮肤，然后参考 `assets/coords.png` 的做法标注着量。

## 常见改造配方

### 加一个新数据项

1. 先看有哪些数据可用：在皮肤页面里
   `JSON.parse(localStorage.bg_sensor_data)` —— 里面所有字段都能取
2. 在 `inject_main.py` 的 `ITEMS` 数组里加一条：

```js
var ITEMS = [
  { id: 'mbt',  label: '主板温度', key: 'mb_t' },
  { id: 'cpu_f', label: 'CPU频率', key: 'cpu_f' },   // ← 新增
];
```

3. 在 `vals()` 里补上取值：

```js
function vals() {
  ...
  return {
    mb_t: f(mb.temp, 'C'),
    cpu_f: f(cpu.freq, 'MHz'),   // ← 新增
  };
}
```

4. 在 `tune.json` 的 `tops` 里给它一个位置

### 改字号 / 颜色

在 `tune.json` 的 `css` 里加：

```css
.mtc-it{font-size:24px !important;color:#ffd700 !important;}
```

### 挪动主排（内存/显存行）

```css
.ProgressBar.outside.AeeAndCui{transform:translateY(-6px) !important;}
```

## ⚠️ 改 CSS 之前必读

**改任何选择器之前，先确认这个选择器匹配几个元素。**

方法：在皮肤页面 console 里跑

```js
document.querySelectorAll('你的选择器').length
```

原因：Myth.Cool 的类名很多来自**配置数据**（`customClass`），不是写死的字面量 ——
同一个类会被**多个 Vue 组件实例复用**。本项目就因为这个踩过大坑（见 [04-踩坑合集](04-踩坑合集.md) 第 2 条）。

**优先用「运行时内容特征」定位**（比如"块里的 span 文本是 `MB/s`"），而不是类名。
